0. ติดตั้งตั้งแต่แรก (เครื่องใหม่)

ทางลัด: เปิด Claude Code หรือ Codex ใน PowerShell → วาง prompt ติดตั้ง (ขอไฟล์ได้จากผู้ดูแลกองเรือ) ลงไป → agent ถาม 3 ข้อแล้วติดตั้งให้ครบตามขั้นด้านล่าง

ถ้าจะทำเอง ให้รันทีละขั้นใน PowerShell (คั่นคำสั่งด้วย ;) และดูผลให้ผ่านก่อนไปขั้นถัดไป

ขั้น 1 — เตรียมเครื่อง

winget install --id Git.Git -e          # ถ้ายังไม่มี git
$ROOT = 'D:\fleet'                       # ไม่มีไดรฟ์ D: ใช้ C:\fleet · ห้ามอยู่ใน OneDrive ห้ามมีช่องว่าง
New-Item -ItemType Directory -Force "$ROOT\apps","$ROOT\downloads","$ROOT\codenames","$ROOT\logs" | Out-Null

ขั้น 2 — ติดตั้ง codename

irm https://raw.githubusercontent.com/oldevill14/codename-fleet/main/install.ps1 | iex
codename --version                      # ต้องได้ codename 0.2.1 ขึ้นไป

ตัวติดตั้งตรวจ SHA256 เองและวางไฟล์ที่ %USERPROFILE%\.local\bin\ · ถ้าพิมพ์ codename แล้วไม่เจอ ให้เปิด PowerShell ใหม่

ขั้น 3 — สำรองค่าตั้งของ agent ก่อนลง Orca

codename setup --root $ROOT

รอบนี้ exit 1 ได้ (ยังไม่มี Orca) ขอแค่เห็นบรรทัด config baseline written · ไฟล์สำรองอยู่ใน %USERPROFILE%\.codename\backups\

ขั้น 4 — ติดตั้ง Orca (ของ stablyai เท่านั้น)

$rel = irm https://api.github.com/repos/stablyai/orca/releases/latest
$ver = $rel.tag_name.TrimStart('v')
$f = "$ROOT\downloads\orca-windows-setup-$ver.exe"
irm ($rel.assets | ? name -eq 'orca-windows-setup.exe').browser_download_url -OutFile $f
$yml = irm ($rel.assets | ? name -eq 'latest.yml').browser_download_url
$want = ([regex]'(?m)^sha512:\s*(\S+)').Match($yml).Groups[1].Value
$got = [Convert]::ToBase64String(([byte[]] -split ((Get-FileHash $f -Algorithm SHA512).Hash -replace '..','0x$& ')))
if ($got -ne $want) { throw "SHA512 ไม่ตรง — หยุด" } else { "SHA512 ok ($ver)" }
Start-Process $f -ArgumentList '/S',"/D=$ROOT\apps\Orca" -Wait
[Environment]::SetEnvironmentVariable('CODENAME_ORCA_BIN', "$ROOT\apps\Orca\resources\bin\orca.exe", 'User')
[Environment]::SetEnvironmentVariable('ORCA_TELEMETRY_DISABLED', '1', 'User')
$env:CODENAME_ORCA_BIN = "$ROOT\apps\Orca\resources\bin\orca.exe"; $env:ORCA_TELEMETRY_DISABLED = '1'
ระวัง: ใช้ orca.exe เท่านั้น ห้ามชี้ไปที่ orca.cmd · อย่าลง "orca" ตัวอื่นจาก winget · เปิดแอป Orca เองหนึ่งครั้งแล้วปิดการส่งสถิติใน Settings → Privacy

ขั้น 5 — ให้ Orca รันเบื้องหลัง + setup จริง

codename serve-task install
codename serve-task status
codename setup --root $ROOT
codename doctor

ต้องเห็น PASS: orca binary, orca runtime, telemetry off, registry, fleet paths · WARN ที่ยอมรับได้: arra memory และ agent configs changed (Orca ใส่ hook) · ถ้า runtime ยังไม่ขึ้น: schtasks /Run /TN codename-orca-serve

ขั้น 6 — ให้กำเนิด codename ตัวแรก

codename birth --choose --engine codex --role "แรงงานโค้ดของเครื่องนี้"
codename list
codename ask <ชื่อที่ได้> "แนะนำตัวหน่อย ชื่ออะไร เผ่าอะไร"

ถ้าจะใช้ร่าง claude ต้องรัน claude แล้ว /login เองก่อน · ถ้าติด blocked ใช้ codename peek <ชื่อ> ดูหน้าจอ (ห้ามกดยอมรับแทน) · โหมดฟรีดูหัวข้อ 8

1. ของที่ติดตั้งอยู่ที่ไหน

ตัวอย่างนี้ใช้ที่วางกองเรือ D:\fleet ถ้าเลือกที่อื่นให้แทนค่าตาม

ของอยู่ที่ไหน
codename (คำสั่งหลัก)%USERPROFILE%\.local\bin\codename.exe · พิมพ์สั้นๆ ว่า cn ก็ได้
Orca (แอปที่ถือหน้าจอ terminal ของ codename)D:\fleet\apps\Orca · รันเบื้องหลังเองทุกครั้งที่ล็อกอินผ่าน scheduled task codename-orca-serve ไม่ต้องเปิดหน้าต่าง
บ้านของกองเรือD:\fleet · codename แต่ละตัวอยู่ใน D:\fleet\codenames\<ชื่อ>
ทะเบียนและค่าตั้ง%USERPROFILE%\.codename\ (fleet.json, engines.json, config.json, logs\)
Claude Code / Codexต้องติดตั้งและล็อกอินเองก่อนสร้าง codename ร่างนั้น (เปิด claude แล้วพิมพ์ /login)
ความจำกลาง arraไม่บังคับ · ถ้าไม่ได้ลง remember / recall จะใช้ไม่ได้

2. เริ่มวัน / จบวัน

เปิด PowerShell (หรือ Windows Terminal) แล้วพิมพ์:

codename doctor        # ตรวจสุขภาพ ทุกบรรทัดควรเป็น PASS (WARN บางข้อรู้อยู่แล้ว ดูข้อ 9)
codename startup       # ปลุกทั้งกองเรือ (หลังรีบูต/ล็อกอินใหม่)
codename list          # ดูว่าใครตื่น ใครหลับ ใครกำลังทำงาน

เลิกงาน:

codename shutdown      # ให้ทุกตัวหลับ ลูกเรือก่อน กัปตันทีหลัง (บ้านและความจำอยู่ครบ)
สถานะใน list: rest = หลับ · idle = ตื่น ว่าง · working = กำลังทำงาน · blocked = ติดหน้าต่างที่ต้องให้คนตัดสินใจ (ใช้ peek ดู)

3. คำสั่งทั้งหมด

ทุกคำสั่งใส่ --help ดูรายละเอียดได้ · ใส่ --json ได้ผลแบบให้โปรแกรมอ่าน · ชื่อในวงเล็บคือชื่อย่อที่ใช้แทนกันได้

คำสั่งทำอะไร
setup (init)ตั้งค่าครั้งแรก · --free = เพิ่ม engine โหมดฟรี
startup (up)ปลุกทั้งกองเรือ
shutdown (down)ให้ทั้งกองเรือหลับ
list (ls)ตารางสมาชิก
birth (bud)ให้กำเนิด codename ใหม่
wakeup <ชื่อ> (wake)ปลุกตัวเดียว (คุยต่อจากเดิม · --fresh = เริ่มบทสนทนาใหม่)
sleep <ชื่อ> (rest)ให้หลับตัวเดียว
hey <ชื่อ> "ข้อความ"ส่งข้อความแล้วไปทำอย่างอื่นต่อ ไม่รอ
ask <ชื่อ> "ข้อความ"ส่งแล้วรอ พิมพ์เฉพาะคำตอบล่าสุด (รอสูงสุด 600 วิ · --timeout)
wait <ชื่อ>รอจนว่าง
peek <ชื่อ>ดูหน้าจอล่าสุดของ codename
wt <ชื่อ> <slug>สร้าง worktree แยกให้งานโค้ด
team up|status|downทีมงานโค้ดจากไฟล์ charter
report "ข้อความ" (done)codename รายงานกลับหากัปตัน
remember (learn) / recall (search)จด / ค้นความจำกลาง (ต้องมี arra)
serve-task install|remove|status (svc)จัดการ task ที่รัน Orca เบื้องหลัง
doctor (check)ตรวจสุขภาพทั้งระบบ

รหัสออกของ wait/ask: 0 = เสร็จ · 2 = หมดเวลา · 3 = ติดหน้าต่างที่ต้องให้คนตอบ

4. คุยกับ codename

codename ask Lyra "สรุปสิ่งที่ทำวันนี้ให้หน่อย"
codename hey Lyra "ช่วยรันเทสต์ในโปรเจกต์ X แล้วรายงานกลับ"
codename wait Lyra
codename peek Lyra
อยากเห็นหน้าจอจริงของ codename: เปิดแอป Orca จาก D:\fleet\apps\Orca\Orca.exe จะเห็น terminal ของทุกตัว (ดูได้ แต่อย่าเปิด agent ซ้ำในบ้านเดียวกันจาก UI ของ Orca)

5. ให้กำเนิด codename ใหม่

# ให้ codename ตั้งชื่อตัวเองตามธรรมเนียมเผ่า (แนะนำ)
codename birth --choose --engine codex --role "แรงงานโค้ดโปรเจกต์ X"

# หรือตั้งชื่อให้เอง
codename birth Lyra --engine claude --role "ผู้ช่วยเอกสาร"
  • engine ที่มี: claude (ต้องล็อกอินก่อน) · codex · grok · hermes · และ claude-free / codex-free หลังเปิดโหมดฟรี
  • หลังเกิด โปรแกรมจะให้สมาชิกใหม่แนะนำตัว (ชื่อ, เผ่า codename, พี่เก่งเป็นผู้ก่อตั้ง, ลงท้าย ค่ะ) ถ้าไม่ผ่านจะแจ้ง · ข้ามได้ด้วย --no-verify
  • --captain = ตั้งเป็นกัปตัน (มีได้ตัวเดียว) · --no-wake = เกิดแล้วยังไม่ต้องปลุก

6. งานโค้ด: worktree และทีม

codename wt Lyra fix-login            # worktree แยกชื่อ fix-login ให้ Lyra
codename team up %USERPROFILE%\.codename\teams\x.yaml  # ตั้งทีมจาก charter
codename team status
codename team down                     # ปิดทีม: commit งานค้างลง branch ก่อนลบ worktree

charter (YAML) มี name, repo (ชื่อ codename หรือ path ของ git repo), lead (ไม่บังคับ), workers (name, engine, task) · engine โหมดฟรียังเป็นลูกทีมไม่ได้

7. ความจำกลาง (arra)

codename remember "บทเรียน: ..."
codename recall "คำค้น" --limit 5
ต้องมี arra รันอยู่ที่พอร์ต 47778 · ถ้ายังไม่มี doctor จะขึ้น WARN arra memory

8. โหมดฟรี (Free Claude Code)

ให้ codename ใช้โมเดลฟรี (เช่น NVIDIA NIM ประมาณ 40 ครั้ง/นาที) แทนบัญชีที่จ่ายเงิน เหมาะกับงานเบา · โมเดลฟรีพูดไทยและรักษาบุคลิกได้แย่กว่า

ขั้นที่ 1 — ติดตั้ง FCC (ทำเองใน PowerShell)

& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.ps1")))
  • ตอนถามว่าจะลง Claude Code / Codex ไหม → ตอบ ไม่ (มีอยู่แล้ว เดี๋ยวซ้อนกัน)
  • เปิด Admin UI ของ FCC → Providers → NVIDIA NIM → Add key (สร้างคีย์ที่ build.nvidia.com/settings/api-keys) → Save → Apply
  • ตั้ง Host = 127.0.0.1 และเปิด Proxy Authentication (ค่าเริ่มต้นเปิดให้ทุกเครื่องใน LAN/Tailscale ใช้คีย์เราได้)
  • อย่ากด Integrations → Connect ให้ Claude Desktop / VS Code ถ้าไม่ได้ตั้งใจให้แอปพวกนั้นใช้โมเดลฟรีด้วย

ขั้นที่ 2 — เปิดใช้ใน codename

codename setup --free
codename doctor          # หัวข้อ free mode ควรเป็น PASS
codename birth --choose --engine claude-free --role "ผู้ช่วยงานเบา" --no-verify

ถ้า FCC ล่มหรือยังไม่ใส่คีย์ codename จะหยุดและบอกให้เปิด Admin UI / รัน fcc-doctor — ไม่ต้อง /login ในโหมดฟรี

9. แก้ปัญหา

อาการทำอย่างไร
runtime_unavailable / doctor บอก orca runtime ไม่พร้อมcodename startup · ถ้าไม่หาย codename serve-task status แล้วล็อกเอาต์-ล็อกอินใหม่ หรือเปิดแอป Orca
codename สถานะ blockedcodename peek <ชื่อ> ดูว่าติดหน้าต่างอะไร (ล็อกอิน, ถามเรื่อง hook, API key) → เจ้าของเครื่องตัดสินใจเอง codename จะไม่กดแทน
"is not logged in" ตอน birth/wakeupเปิด claude (หรือ codex) ใน PowerShell แล้วล็อกอินเอง แล้วสั่งใหม่
WARN agent configs changed since baselineOrca ใส่ hook ในไฟล์ตั้งค่าของ claude/codex/gemini · ตอนนี้ปล่อยไว้ (ใช้ได้ปกติ) · ไฟล์ก่อนถูกแก้อยู่ที่ %USERPROFILE%\.codename\backups\pre-orca-*\files\ คัดลอกกลับได้ถ้าต้องการคืนค่า
WARN arra memoryยังไม่ได้ลง arra (ข้อ 7)
doctor บอก "started twice?"มีคนเปิด agent ซ้ำในบ้านเดียวกัน → ปิดตัวที่เปิดเองใน Orca
ภาษาไทยเป็น ??? ใน PowerShellแค่หน้าจอ console · ไฟล์จริงถูกต้อง · ใช้ Windows Terminal หรือเปิดไฟล์ดูแทน
อยากดูว่า codename ทำอะไรไปlog รายวันที่ %USERPROFILE%\.codename\logs\ · หรือเติม --verbose ท้ายคำสั่ง

10. ข้อห้ามและไฟล์สำคัญ

  • ห้ามวางกองเรือในโฟลเดอร์ OneDrive · ใช้เช่น D:\fleet
  • ห้ามชี้ CODENAME_ORCA_BIN ไปที่ orca.cmd — ต้องเป็น D:\fleet\apps\Orca\resources\bin\orca.exe (กันช่องโหว่ BatBadBut)
  • อย่าเปิด agent ซ้ำจาก UI ของ Orca ในบ้านที่ codename คุมอยู่
  • codename ไม่ล็อกอินแทน ไม่กดยอมรับข้อตกลง และไม่ตั้ง ANTHROPIC_* ให้ใคร — เรื่องพวกนี้เจ้าของเครื่องทำเอง
